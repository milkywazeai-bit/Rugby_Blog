# 지금 섭취하는 비타민 기본 베이스

제가 섭취하는 비타민 기본 베이스 입니다.
​
유산균 + 오메가3 + 크릴오일 + 비타민B(or 종비)
​
이것말고도 정말 많은 종류 섭취하지만
​
처음 섭취하신다면 유산균 + 오메가3 + 크릴오일 + 비타민B 로 입문하시면 좋을듯 하네요.
​
제 기준 1티어 제품들입니다.
